# Homebrew tap reference

The live cask belongs to [blas0/homebrew-omjo](https://github.com/blas0/homebrew-omjo).
This copy stays with the app as a release template.

After building a release, update the version and SHA-256 in the standalone tap
on a new branch. Run `brew audit --cask Casks/oh-my-just-open.rb` before opening
the pull request.
